# PRD — 미니 이커머스 장바구니 시뮬레이터

| 항목 | 내용 |
|------|------|
| 문서명 | Product Requirements Document |
| 제품명 | 미니 이커머스 장바구니 시뮬레이터 |
| 단계 | 3단계: Redux Toolkit 전역 장바구니 + Firebase Auth |
| 버전 | 3.4 |

---

## 1. 제품 개요

[FakeStore API](https://fakestoreapi.com/products)에서 상품 목록을 가져와, 사용자가 장바구니에 담고 수량을 조절하며 총액을 확인할 수 있는 **프론트엔드 장바구니 시뮬레이터**이다. 실제 결제·자체 백엔드·영속화는 포함하지 않는다.

1단계 장바구니 핵심 로직(담기, 수량 ±, 총액 파생)은 유지한다.  
2단계에서는 API를 우선 사용하고, **네트워크 실패 시 로컬 mock으로 폴백**하여 시뮬레이터를 계속 사용할 수 있게 한다.  
3단계에서는 장바구니를 **Redux Toolkit 전역 상태**로 공유하고, **Firebase Authentication(Google)** 으로 로그인·인증 상태 유지·로그아웃을 제공한다. 로그인 전에도 상품 열람과 장바구니 사용을 허용한다. 인증(`authSlice`)과 장바구니(`cartSlice`)는 별도 상태로 두되, **로그아웃 시에는 장바구니를 비운다**.

---

## 2. 목표

### 1단계 기반 (유지)

- 상품 목록을 화면에 표시하고, 「담기」로 장바구니에 추가할 수 있다.
- 장바구니에서 수량을 증가·감소할 수 있으며, 수량이 1일 때 감소 시 항목이 제거된다.
- 장바구니 총액은 별도 상태 없이 `cartItems`와 `products`를 매핑한 **파생 값**으로 실시간 계산된다.
- 장바구니가 비어 있으면 「담긴 상품이 없습니다」를 표시한다.

### 2단계 추가

- `https://fakestoreapi.com/products`에서 상품 목록을 가져온다.
- 로딩 중 「상품을 불러오는 중입니다...」를 표시한다.
- 요청 실패 시 「오류 발생」을 알리고, **로컬 mock 상품으로 목록을 대체**한다 (빈 화면이 되지 않음).
- API 성공 시에는 FakeStore 상품만 표시한다 (mock과 병합하지 않음).

### 3단계 추가

- 장바구니를 **Redux Toolkit `cartSlice`** 로 관리하고, 상품 목록·장바구니 컴포넌트가 동일 store를 공유한다.
- **Firebase Google 로그인**으로 로그인·인증 초기 상태 확인·실패 안내·로그아웃을 구현한다.
- 인증 상태를 Redux `authSlice`에 두고, 단일 `AuthListener`가 `onAuthStateChanged`로 세션을 추적한다.
- 로그아웃·세션 종료 시 장바구니(`clearCart`)를 비운다. 게스트 최초 로드에서는 비우지 않는다.

---

## 3. 비목표 (Out of Scope)

다음 항목은 3단계 범위에 포함하지 않는다.

- API 상품과 mock 상품을 **항상 함께** 목록에 병합 표시
- 로컬스토리지 / 세션 영속화
- 자체 백엔드·결제 API
- 라우팅, 회원 등급·프로필·주문 내역
- Context / Zustand 등 **Redux Toolkit 외** 전역 상태 라이브러리
- 결제·체크아웃·쿠폰·재고 관리
- 사용자별 장바구니 DB 저장
- 전화번호 인증·다중 소셜 로그인

## 4. 사용자 스토리

| ID | 스토리 | 수용 기준 |
|----|--------|-----------|
| US-01 | 사용자는 API 상품 목록을 본다 | 성공 시 FakeStore 상품이 `title`·가격·이미지와 함께 표시된다 |
| US-02 | 사용자는 로딩 상태를 인지한다 | 「상품을 불러오는 중입니다...」가 보인다 |
| US-03 | 사용자는 오류를 인지하고 계속 쓴다 | 실패 시 「오류 발생」+ 폴백 안내와 함께 로컬 상품 목록이 보인다 |
| US-04 | 사용자는 상품을 장바구니에 담는다 | 「담기」 시 추가, 이미 있으면 수량 +1 |
| US-05 | 사용자는 장바구니 수량을 조절한다 | `+`/`-`, 수량 1에서 `-` 시 삭제 |
| US-06 | 사용자는 총액을 확인한다 | 총액 = 가격 × 수량 합 |
| US-07 | 사용자는 빈 장바구니를 인지한다 | 「담긴 상품이 없습니다」 |
| US-08 | 사용자는 Google로 로그인·로그아웃한다 | 초기 인증 확인 후 로그인/비로그인 UI가 맞고, 실패 시 안내, 로그아웃 시 비로그인 상태로 돌아가며 장바구니가 비워진다 |
| US-09 | 사용자는 전역 장바구니를 공유한다 | Redux store의 cart가 상품 목록과 장바구니 UI에 동시에 반영되고, 총액은 selector(파생 값)로 계산된다 |

---

## 5. 기능 요구사항 요약

1. **상품 목록 (성공)**: FakeStore API 응답을 렌더링한다.
2. **상품 목록 (실패 폴백)**: `mockProducts`로 대체하고 오류 배너를 표시한다.
3. **로딩**: fetch 중 안내 문구.
4. **담기 / 수량 / 총액 / 빈 상태**: 1단계와 동일 (데이터 소스만 API 또는 mock). 3단계부터 cart는 Redux 전역 상태.
5. **Firebase Auth**: Google 로그인, 인증 초기 상태, 실패 안내, 로그아웃.
6. **Redux 장바구니**: `cartSlice` + Provider로 컴포넌트 간 cart 공유.
7. **상품 검색**: 상품명 검색어로 목록을 필터링하고, 결과가 없으면 안내 문구를 표시한다.

---

## 6. 성공 지표 (3단계)

- 정상 네트워크: 로딩 → FakeStore 목록 → 전역 장바구니 동작.
- 네트워크 실패: 「오류 발생」배너 + 로컬 mock 목록으로 장바구니 시뮬 가능.
- 인증: 초기 상태 확인 → Google 로그인 → 사용자 표시 → 로그아웃 시 장바구니 비움.
- 전역 cart: 상품 담기 후 장바구니·총액이 동일 Redux 상태를 반영.
- 검색: 상품명 검색 결과와 0건 안내가 정상적으로 표시된다.
